# VLAN Configuration Lab

## 📖 Overview

This lab demonstrates VLAN creation, switch port assignment, and communication testing between different VLANs using Cisco Packet Tracer.

## 🎯 Objective

- Create VLAN 10 and VLAN 20
- Assign ports to each VLAN
- Verify communication within the same VLAN
- Prevent communication between different VLANs

## 🛠 Tools

- Cisco Packet Tracer

## 📂 Files

- VLAN-Lab.pkt
- Topology.png
- Screenshots

## 🧪 Verification

- Successful communication within VLAN 10
- Successful communication within VLAN 20
- Communication blocked between VLAN 10 and VLAN 20

## 📚 Learning Outcomes

- VLAN Configuration
- Switch Port Assignment
- Broadcast Domain Segmentation
- Network Isolation
